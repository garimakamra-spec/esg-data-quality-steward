# Workflow: eg-brainstorm

## Goal
Generate divergent perspectives on a rough product idea and converge on a validated concepts brief.

## Procedure
1. **Clarify Framing:** Ask the user:
   - What stage is this idea in? (Raw seed vs. pivot)
   - Breadth target: ~10 quick concepts or ~20 deep variations?
2. **Form the Seed:** Draft a 1–2 sentence problem statement seed and get user confirmation.
3. **Dispatch Parallel Evaluators (Goldfish):**
   Run four independent passes with zero shared conversational context:
   - **Technical Lens:** What architecture or tech stack enables an unfair advantage?
   - **Business Lens:** What drives adoption, defensibility, and monetization?
   - **UX Lens:** What is the critical path workflow and where is friction eliminated?
   - **Contrarian Lens:** What consensus assumption in this space is dead wrong?
4. **Contrarian Sweep:** Review the deduped ideas and ask: *"What did all four lenses miss?"* Generate 2–3 outsider angles.
5. **Synthesize:** Cluster the concepts, rank the top 3 picks, highlight key trade-offs, and output the **Concepts Brief**.
